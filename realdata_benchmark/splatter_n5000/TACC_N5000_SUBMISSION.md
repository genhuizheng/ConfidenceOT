## What is run

- **Levels** (cumulative; each adds one factor, values fixed in `20_generate_n5000.R`):
  - L0_matched, L1_depth, L2_depth_dropout: frozen native definitions, regenerated with the same seeds and checked cell
    for cell against `benchmark_native/generated` (`25_check_native_identity.py`); when identical the frozen fits are
    reused, otherwise the rows are refitted.
  - L3_batch = L2 + batch effect (Splatter batch factors, facScale = sqrt(0.5 D / 2)).
  - L4_batch_perturb = L3 + target perturbation of Group1 (shared; label kept; 0.5 D).
  - L5_batch_perturb_imbalance = L4 + target proportions 0.40 / 0.25 / 0.15 / 0.12 / 0.08.
  - Ablations: A4_perturb_only = L2 + perturbation; A5_imbalance_only = L2 + imbalance.
  - L3-L5 and the ablations use L2's seed: paired with L2.
- **N**: 5,000 cells per side (the native semantics), recorded in every manifest.
- **Cases**: Case 1 all shared, Case 2 source-unmatched and target-unmatched, Case 3 none shared: 4 pairs per level.
- **Replicates**: 1-3.
- **Configurations** (8): logcpm, ranknm256 production ties, ranknm1024 expected ties, rankhvg2000 midrank; DS none and
  P10 seed 1; no gene scaling; cosine. Raw excluded. The full 40-configuration grid at L0-L2 already exists and is reused.
- **Per row**: M4-E / M4-R fit (or the frozen fit), 40_score, IC-POT (c = 0.5) and Vanilla UOT on the same cost
  (`50_solver_comparison.py`), entropic balanced OT full and on the M4-E retained block, DEG-B. Per condition: DEG-A / C / D.

## Task counts

18 base scenarios = 6 levels x 3 cases (Case 2 in both directions, so 24 pairs per replicate), plus 8 ablation pairs.

## Resources (estimates; the pilot measures them)

- **Generation**: two Splatter calls of 10,000 cells x 10,000 genes per level; estimated 5-15 min and a few GB each;
  8 levels per job well inside 6 h.
- **Rows**: the joint benchmark's N = 5,000 fits took a few minutes each (3,456 Splatter rows in about 1.3 h on 6 nodes
  with 18 workers per node). Each row now adds IC-POT (network simplex on 5,001 x 5,001), Vanilla UOT, two balanced OT
  solves and a Wilcoxon DEG: about 10 min for a new fit, 6 min for a reused one.
  - Estimate: (480 x 10 + 288 x 6) / 60 = about 110 worker-hours, / 18 per node = about 6 node-hours.
  - So 4 nodes x 6 h, resubmitted if needed (finished rows are skipped).
  - Memory: about 0.2 GB per 5,000 x 5,000 float64 matrix, a few per row; 18 rows per node fit.
- **Job cap**: at most 4 run jobs + 3 generation jobs queued at once, well under 40.
