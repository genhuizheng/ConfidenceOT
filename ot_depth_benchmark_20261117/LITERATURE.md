# Optimal-transport methods for single-cell matching and perturbation

Compiled 2026-11-17. Venues, DOIs and arXiv ids were checked against Crossref, arXiv, PMLR, NeurIPS and JMLR. PyPI versions and licences were read from the PyPI JSON API, and GitHub licences from the GitHub API. Function defaults were read from each package's source on its default branch on that date. Anything not checked this way is marked **unverified**.

Notation: epsilon is the entropic regularisation. tau is ott-jax/moscot's marginal relaxation, tau = lambda/(lambda+epsilon), where tau = 1 is balanced. lambda (POT `reg_m`) is the KL marginal-penalty weight, so lambda = epsilon*tau/(1-tau). m is the transported mass in partial OT.

## Comparable on one source/target task

**(A) Direct couplings on one fixed cost matrix and one cell set.** These methods can be compared fairly at the coupling level: overlap of couplings, per-cell retained mass, and coupling correlation with nCount / nFeature against biological labels.

- exact balanced EMD
- entropic balanced Sinkhorn
- entropic unbalanced OT
- partial OT
- the ConfidenceOT gate
- an independent coupling P = a b^T as the null

All take the same C, a and b, so any difference is due to the solver or gate, not to preprocessing. Fix C once: our representation, with cost rescaled by its mean or median and the rule reported. Use the same epsilon across the entropic arms.

**(B) Learned maps: CellOT, CondOT, OT-CFM, GENOT, CellFlow, Meta Flow Matching.** These output T(x) or a generator, not a coupling on the observed cells. Compare them only on held-out distribution-level metrics: energy distance, MMD, Wasserstein distance between T(source) and held-out target, and marker-gene means. Never compare them on coupling overlap. To check depth-following, test whether predicted shifts correlate with source nCount.

**(C) Time-series methods: WOT, moscot TemporalProblem, TrajectoryNet, MIOFlow, JKOnet, PRESCIENT.** Their growth terms and dynamics need ordered time points and a time gap. Control to perturbed is not a time series, so these methods do not apply without adaptation. moscot's generic `SinkhornProblem` (no growth) is a group-A solver and can stand in.

**(D) Perturbation-response OT: CINEMA-OT.** It first removes treatment-associated ICA components and matches only on confounder ICs. It returns a balanced matching matrix plus per-cell treatment effects. Because it changes the cost space, compare it to group A on the downstream readouts (which control cells pair with which perturbed cells, and whether matching tracks depth), not on a shared C. It applies to control to perturbed only.

## Recommended methods for a fair comparison

Recommended set: arms 1-4 below (group A) plus the a⊗b null, on both tasks. On control to perturbed, also run CINEMA-OT (arm 5). CellOT is optional and may be scored only on distribution-level metrics.

To isolate the gate, run arms 2 and 3 at **ConfidenceOT's own epsilon and lambda** (api defaults epsilon=0.1, lambda_a=lambda_b=1, i.e. tau = 1/1.1 ≈ 0.909). Also run them at the literature defaults below.

1. **Exact balanced OT.** Paper: Flamary et al., JMLR 2021. Code: POT 0.9.7.post1, `ot.emd(a, b, C)`, with uniform a and b and numItermax raised (e.g. 1e6) for large n. Input: fixed C. Output: sparse coupling.
2. **Entropic balanced OT.** Paper: Cuturi, NeurIPS 2013. Code: `ot.sinkhorn(a, b, C, reg=eps)`. POT has no default epsilon. Literature defaults depend on how C is scaled:
   - WOT: epsilon=0.05 on a median-normalised cost.
   - moscot: epsilon=1e-3 on a mean-scaled cost (`SinkhornProblem.solve`, tau_a=tau_b=1).

   Use stopThr=1e-9 and numItermax of at least 1000, and check the convergence log. Output: dense coupling.
3. **Entropic unbalanced OT (no gate).** Papers: Chizat et al., Math. Comp. 2018; Liero-Mielke-Savaré 2018. Code: `ot.unbalanced.sinkhorn_unbalanced(a, b, C, reg=eps, reg_m=(lambda_a, lambda_b), reg_type="kl")`. Literature settings:
   - WOT: lambda1=1 (source), lambda2=50 (target), epsilon=0.05 on a median-normalised cost.
   - moscot: tau_a, tau_b < 1 with lambda = eps*tau/(1-tau).

   Output: coupling plus per-cell row-sum deficit. This is the same model as ConfidenceOT without the gate.
4. **Partial OT.** Papers: Figalli 2010; Chapel et al., NeurIPS 2020. Code: `ot.partial.partial_wasserstein(a, b, C, m=m)`. Always pass m explicitly, because `m=None` switches to the Lagrangian variant. There is no published default m. Run two settings:
   - (i) m equal to the mass ConfidenceOT retains on the same pair (a matched-mass comparison);
   - (ii) a fixed grid, e.g. 0.5 to 0.9.

   Output: exact zero rows = unmatched cells, directly comparable to gate rejections.
5. **CINEMA-OT (control to perturbed only).** Paper: Dong et al., Nat. Methods 2023. Code: pertpy 1.5.1 `pt.tl.Cinemaot().causaleffect(adata, pert_key=..., control=..., return_matching=True, use_rep="X_pca", dim=20, thres=0.15, smoothness=1e-4, eps=1e-3, solver="Sinkhorn")`. This is the original `cinemaot.cinemaot_unweighted` with the same defaults; the authors' tutorial uses thres=0.5. Input: AnnData with PCA in `X_pca`. Output: matching matrix, `cf` confounder components, per-cell TE AnnData.

**Baseline for every task:** the independent coupling P = a b^T (uniform a, b). It gives the coupling-level floor. Any depth correlation a method shows above this null comes from the cost or solver, not from marginals.

**Not recommended for this question:** WOT and moscot `TemporalProblem` (they need time points and growth; see C), and the learned maps in group B for coupling-level claims.
